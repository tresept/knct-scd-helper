# 香川高専 時間割 JSON 入力ツール

PDFの時間割を見ながら、学年・クラス単位で月曜日から日曜日までの授業を入力し、JSONとして保存するためのローカルWebアプリです。

## 起動

```sh
bun install
bun run dev
```

表示されたURLをブラウザーで開いてください。

## 候補データ

候補リストは `src/catalogs/` 内のTOMLで管理します。画面での自由入力もできます。

- `teachers.toml`: 教員候補。DG（一般教育科）は全学科に共通で表示し、CN / ES / IT は選択した学科に応じて表示
- `subjects.toml`: 学年別の一般教育科目と、CN / ES / IT の学科別科目。両方を候補に表示
- `rooms.toml`: 学年別の教室候補

入力した時間割はブラウザーのローカルストレージに下書き保存します。科目と教員・教室の組み合わせ履歴もこの端末内に保存し、同じ学科・科目を入力した際に補完します。

## JSON形式

`src/schedule.schema.json` が出力形式と検証ルールの定義です。曜日は授業配列で表し、各項目に `period` を明記します。授業がない曜日は空配列です。2〜5年はクラス選択から学科を自動設定し、1年はクラスと所属学科をそれぞれ選択します。
